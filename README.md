# AI Job Tracker

A premium Job Application Tracker with AI insights.

## Tech Stack
- MERN Stack (MongoDB, Express, React, Node.js)
- Vite, Tailwind CSS, Shadcn UI, Framer Motion

## Setup

### Backend
1. `cd backend`
2. `npm install`
3. `npm run dev`
   - Runs on http://localhost:5000

### Frontend
1. `cd frontend`
2. `npm install`
3. `npm run dev`
   - Runs on http://localhost:5173

## Features
- Authentication
- Dashboard with Glassmorphism UI
- Application Tracking
